# Fixed class psychic entitlements

Core class definitions may bind an exact source path pack with `ability_path: {id, version}`. Binding compilation validates every declared dependency before generation dice, including classes the player did not choose. Portable bundles carry those exact dependencies so an inactive malformed definition cannot be hidden by selecting another class. Older core definitions have no binding and retain their existing behavior.

`ability-paths-v2` describes a fixed psychic classification using `fixed_path`, without a percentile table or invented percentile result. The retained path's `face` remains null, and rolling potential on a fixed path is rejected before dice. It reuses ability selections, prerequisites, original acquisitions, resource contributions, level gains, and source projections. Counts may include exact milestone awards and weighted costs. Counts and prerequisites remain player guidance; excess selections remain saved.

The application stores class powers in `class_psionics` and ordinary natural potential in `psionics`. The composition boundary preserves both origins, including overlapping powers with different source restrictions. Class psychic status controls overlapping resource capacities and the saving target. It never sums a second M.E. contribution or a second complete I.S.P. base. Natural rolls, powers, and original reserve acquisitions remain available in their own source view. Undo restores prior choices and retains acquired level dice for replay; portable validation checks both resource attribute snapshots against their exact racial/class sources.

## Psi-Operator interpretation

Original RUE printed 92 defines optional Psi-Operators as Major psychics, with three choices, one additional choice at levels 4, 8, and 12, and half the ordinary related-skill counts. Electrokinesis, Telemechanic Mental Operation, and Telemechanic Paralysis cost two selections each. Secondary counts stay unchanged, and two additional Mechanical skills remain required guidance. Distinct wandering and city source definitions use ordinary Operator attributes and equipment.

Printed 289 permits random psychic ability in addition to O.C.C./R.C.C. abilities. This implementation retains both origins while applying the class's Major classification to the single reserve and saving target. Major I.S.P. starts with recorded M.E. +4D6 and gains 1D6+1 at each later level, following the previously reviewed natural Major definition. A skipped, None, or Minor natural result does not weaken the class classification. This composition is an explicit source interpretation requiring independent review before acceptance.

Class Object Read retains its restriction to a device's history and operation. A separately acquired natural Object Read keeps its ordinary description. The class-specific Total Recall cost is 2 I.S.P., overriding the ordinary power's conflicting 3-I.S.P. prose. Electrokinesis's five source applications and three additional Super powers retain descriptive costs, ranges, durations, and prerequisite guidance; no encounter simulator or permanent engineering-skill grants are introduced.

The protected class-power endpoint uses the same revision/session/origin checks as other selections. The browser labels one- and two-choice powers and displays the effective reserve separately from natural potential. Editable sheets preserve both source descriptions, effective capacity, original resource provenance, weighted guidance, and the Major saving target.

This is a bounded Human class proof. Broader class/race/R.C.C. powers, nonhuman creation, equipment identities, saved identity revision, and robot/bionic construction remain required work. The canonical Operator owner and full amended build are not complete.
