# 22C2: Declarative percentile skill effects

**Status:** in-progress. **Base:** c074870950295374f7831e12ebaf3dd8d4538e66 (merged22E2/PR97; review base2ad72dfd has the identical tree).

Provide one non-executable definition shape for additive percentile effects on acquired skills: stable effect identity, display name, integer amount, shared catalog selector and source citation. Resolve targets once by canonical catalog identities; overlapping selector clauses must apply an effect once. Different declared effects add independently. Effects never grant a skill, fill a slot, or change education eligibility. Apply before the existing percentile cap and additional-check rules.

Prove reuse for Rifts class percentile skills and Heroes program/Secondary skills and selected mutant abilities without option-ID handlers. Preserve all legacy power bonus records and their known missing catalog dependencies; strict new declarations reject missing explicit references rather than claiming those dependencies are certified. Source evidence must accompany projected typed contributions and remain tied to exact pinned definitions in portable reopening. No random acquisitions, conditional/level scheduling, magic/psionic catalog acceptance or new book content in this increment.
