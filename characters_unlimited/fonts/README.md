# PDF editing font

Droid Sans Fallback is bundled from the Android Open Source Project's kitkat-release branch:
https://github.com/aosp-mirror/platform_frameworks_base/blob/kitkat-release/data/fonts/DroidSansFallback.ttf

The accompanying NOTICE contains the copyright notice and Apache 2.0 license. The binary is unchanged. It supplies Latin, Cyrillic, CJK and many symbols without depending on fonts installed on the player's PC. Glyphs beyond its coverage use explicit Unicode codes in initial appearances; the original editable field value remains intact.
