# Shared retained acquisition lifecycle (22F3)

`retained_acquisitions.py` accepts a bounded mapping of at most1000 stable nonempty option identities to at most1000 named ordinary formula groups per option. Shared recorded formula validation applies to every group, including unselected options. Both possible minimum/maximum totals must fit the supported exact integer range; do this before any die rather than discovering an invalid definition after drawing. No names dispatch behavior or expressions execute.

The receipt cache maps known option identities to exact `{rolls: {group: raw_faces}}` objects. Every retained inactive receipt validates against its complete pinned group set and ordinary formula, including exact face count/range and boolean rejection. Selections are a distinct bounded known identity list. `acquire_selected` validates catalog/cache/selections first, returns a deep copy, acquires each missing selected identity once and preserves all inactive receipts. Empty formula groups represent nonrandom abilities. Raw ones are retained; initial attribute house rules never apply. A die-source failure can consume draws but cannot mutate the caller cache or saved character.

`record_constants` is an explicit boolean adapter policy. Default true records zero-die groups as empty arrays; false omits them while still validating their formulas. Physical legacy caches omit zero-die groups, while the Heroes power adapter preserves its original flat floor dice or named additive groups, UUIDs, sources and selection history. Ownership/source/history validation remains with those adapters and exact portable pins. The shared lifecycle owns no attribute effects, grants, active-state semantics, resource spending or level scheduling.

Both games' shared Physical path and the mutant power path now consume this engine. No accepted archive or saved schema changes. Synthetic empty psychic and constant spell identities exercise the library boundary, not complete game adapters or source-reviewed content. Generic ability effects/activation and complete magic/psychic eligibility remain open.
