# Racial creation composition

Core packs may opt into `creation_profile_format: paired-v1`. `creation_profiles` contains one source-bound mapping per declared race: `race`, ordered `classes`, and `source` (book/section). Each class reference must exist and each class must be reachable. The first class supplies that race's creation default. All racial formulas/sources and class attribute effects/guidance preflight, including unselected options, before initial dice or saving. Legacy core packs retain their established cross product.

The same resolver guards creation and portable replay against impossible pairings. Builder race changes filter the new-character class list and retain its selected class when compatible. This is creation-dialog behavior; existing saved identities remain fixed, and full saved-character backtracking is separate required work. Class/R.C.C. mechanics continue to come from their explicit owned skill/equipment profiles: this pairing contract does not merge another class's grants or certify R.C.C. precedence, traits or full content.

Racial pools now support positive integer `multiplier`: `(sum of retained initial dice * multiplier) + constant`. House-rule rerolls/drop happen before multiplication, explicit exceptional dice add afterwards, and class/Physical effects apply afterwards using existing retained receipts. Human formulas without a multiplier retain their results and explanation strings. This differs intentionally from ordinary acquisition formulas `(sum + constant) * multiplier`: attribute notation such as 2D6x10+33 multiplies the dice before adding33. It calculates the racial attribute, not derived movement rates.

Witnesses use synthetic pairings in both games and the Forest Runner Dragon Hatchling's published SPD expression as a numeric fixture. No Dragon/Vagabond or Dragon/City Rat book entitlement is inferred and no accepted archive is changed. With retained dice4/4, base SPD113 plus the fixture's City Rat bonus5 and automatic Running bonus16 yields134. Exact portable replay, raw dice/history, Physical/class receipts and editable SPD export are verified. Source-grounded full class/nonhuman activation remains required before release.

Formula preflight also bounds reachable exceptional gains (unbounded explosions share the existing draw cap); overflow cannot create a save that portable replay rejects. This is a save-integrity guard, not an extra player calculation.
