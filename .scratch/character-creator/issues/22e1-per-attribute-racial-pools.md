# 22E1: Per-attribute racial generation pools

**Status:** in-progress. **Base:**21ab1a3a30f96a80bdbaef68330e682be5b38a9c (merged22D1/PR95).

Complete replacement formulas carry their own exceptional behavior; they must not accidentally inherit human exceptional rules. Validate all pools, target names and caps before the first generation die. Initial/reroll/manual/history/resource snapshot/portable/PDF behavior must use the same pinned per-attribute resolution. No class/race ID handler or new accepted book content. R.C.C. replacement precedence, complete mechanical importer and source-grounded full nonhuman paths remain later work.
