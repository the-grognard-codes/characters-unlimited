# Required Physical choices and scoped skill effects

Required select groups may include an exact nonpercentile Physical catalog definition. The existing required choice module resolves selected definitions, duplicate identities, exclusions and remaining allowances once. Percentile grants and Physical acquisitions consume that result. Physical bonuses use the existing retained acquisition cache and modifier synchronization. Switching or removing a required choice deactivates its bonuses but retains original rolls; reselection restores them. The same Physical identity selected optionally applies once. Existing required Physical percentiles, fixed grants and old archive pins retain their prior behavior.

Validate every Physical alternative against the pinned catalog before generation, including unselected owners. A required Physical declaration cannot alter catalog effects or source evidence. Source O.C.C. provenance belongs to its enclosing choice group; acquired bonuses retain the Physical skill source. Required Physical acquisition runs inside the public revisioned selection workflow, after the revision check and before the candidate save. A stale revision draws no dice.

Additive skill effects may opt into `check_names`, a bounded list of distinct normal check names. `primary` names the main percentile. Other targets must name an ordinary additional check on every matched skill. Derived context checks and fixed intelligence-only checks cannot be targeted directly. Without this field, existing effects preserve their prior behavior.

Each normal check starts from common class, attribute, synergy and growth contributions, then receives its applicable effects. A primary-only effect does not flow into an independent additional check. Derived contexts use their named reference's final percentage, so a Treatment effect reaches Animal treatment while a diagnosis effect does not. Existing caps, growth and exact integer guards remain intact. Builder provenance and editable PDF notes disclose the selected check scope.

Body Fixer supplies source-backed witnesses: Athletics versus Body Building uses retained Physical acquisitions; Medical Doctor receives Disease Diagnostic Specialist only on diagnosis. Shared class numeric contributions now accept reviewed dodge/disarm additions. Repeated starting equipment permits a zero initial elective count so fixed Knife training does not create a blank extra weapon slot; retained numbered receipts survive later training changes.
