# Source learning awards and known class powers

`ability-paths-v3` is an explicit extension for fixed class paths. Existing v1/v2 definitions and saved state shapes are unchanged. Every path declares `known_abilities`, and its named allowances declare source-backed `awards`: unique identity/name, book/section, attained level, bounded count and one or more supported categories. Scalar count and minimum category count are zero; maximum categories matches the catalog. Costs reference elective identities only. Every inactive path, grant, award and cost validates before acquisition dice.

Automatic grants appear among actual known abilities and retained acquisitions, cannot be removed by elective edits, and consume no elective credit. V3 state adds `learning_levels` for every acquisition, including removed choices. Automatic grants are learned at level1. An elective receives its current level on first selection; later removal, reselection, advancement and undo preserve that first level. Higher-level creation records first-selected electives at the creation level rather than inventing earlier individual training dates.

Ordinary selection groups intentionally credit overlapping membership independently. Source learning awards instead allocate each elective's choice units once, to attained awards no later than its original learning level. Cost-one powers with multiple categories credit one matching category exclusively. Weighted powers must declare exactly one source category; their units may span cumulative awards in that category. This lets a later Burster power costing two choices consume one saved initial choice and one newly attained choice. Unsupported weighted multi-category declarations reject during inactive preflight before dice. A bounded maximum-flow allocation avoids order-dependent greedy errors. Projections expose each award's remaining count and any unallocated choice credit. Excess, category mismatch and unmet learning-tier requirements remain visible honor-system guidance; they do not remove powers or require override markers.

Current ability prerequisites remain available alongside original minimum-learning-level guidance. Known powers and learning levels display in the class panel and editable PDF notes. Original natural and class source origins remain independent, while the existing composition owns one effective class reserve. Temporary fields, activation costs and situational power effects remain descriptive under the player-focused amendment.

Portable validation checks complete learning records and agreement with each retained advancement frame. Existing records cannot be rewritten to a different learning level; a new record absent from a prior frame cannot claim training at or before that frame. Undo preserves the complete receipt cache while restoring earlier selections. Old source versions do not gain new fields.

This contract is currently under implementation in05D18. Synthetic public workflows prove the shared seam. Burster/Mind Melter archives, skills and equipment are activated in the isolated local worktree for source-backed checks; they are not yet certified or published. Actual browser/PDF witnesses, full/frozen verification and both independent reviews remain required before publication of that class batch.
