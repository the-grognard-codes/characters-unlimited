# Shared ability requirements (22F2)

Optional `requirements` is a list of at most100 rows with distinct nonempty `id`, nonempty `name`, and `source` containing nonempty `book` and `section`. Each row contains exactly one supported condition: `minimum_level` (integer1-1000), `attribute_minimum` (exact `attribute`/`value`, known adapter attribute and safe nonnegative integer), or `selected_options` (exact `catalog`/`selector`/`minimum`, known adapter catalog, shared selector, integer1-1000). Booleans, unknown fields/operations and missing explicit identities reject. Selector categories may match no options; this is not content-completeness evidence.

`compile_ability_requirements` resolves all declaration dependencies, including unselected definitions. `project_ability_requirements` consumes current integer level, effective attribute values and selected option identities. Count distinct matching identities once. Every condition must hold for all requirements to be met. Projection provides actual values, status, explanation and original citation; no expressions or prose execute. Unknown context data must not be invented by adapters.

The Heroes adapter supplies its separately pinned power catalog, existing effective attributes and active selected powers. Catalog and active/inactive receipt views show status at the current level and selection state. Removal/backtracking changes status without discarding acquisitions or rolling again. Portable current/history validation uses exact archived declarations; a newer active catalog cannot rewrite the old requirements. No new saved receipt format is introduced.

Unmet requirements are honor-system guidance. They retain choices and effects, add cited warnings for active choices, and require no override marker or permission. All catalog cards and active/inactive editable PDF explanations include statuses; inactive choices do not generate active warnings. Costs, casting/activation, construction restrictions, initial-only eligibility, arbitrary alternative condition trees and complete magic/psionic paths remain open. No accepted book definitions change.
