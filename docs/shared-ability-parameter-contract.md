# Shared source-bound ability parameters (22F1)

An ability definition may declare `parameters`, a list of at most100 source-bound display values. Every parameter has a distinct nonempty `id`, nonempty `name` and `source` with nonempty book/section evidence. It contains exactly one of `text` (nonempty literal guidance) or `quantity` (level-scaled whole-number data). Unknown fields/operations reject; no book prose or expressions are executed.

A quantity has exactly `base`, `per_level` and `unit`, with optional `level_origin`0 or1 (default0). Base and rate are nonnegative safe whole numbers; booleans are invalid. Calculation is `base + per_level * (level - level_origin)`. Origin0 represents a contribution at every attained level, including1; origin1 represents increases after level1. Units are explicit nonempty text and never implicitly converted. The current level must be an integer1–1000 and the result must stay within the supported exact-integer range. Fractional/conditional/unreviewed values can remain literal source guidance rather than invented arithmetic.

`ability_parameters.py` projects deterministic values/text/source without knowing game, class or ability names. The Heroes power adapter validates every definition's parameters before new power dice, including unselected powers; active and retained inactive views use current level. Portable validation derives these parameters from exact rule pins, including historical snapshots. No extra random acquisition or saved receipt fields are introduced. Newer active catalogs cannot alter earlier pinned parameter values.

Builder and editable Heroes PDF explanations show parameter text and book/section evidence. Literal conditions and costs are display information; this increment does not spend resources, change saving bonuses, activate conditional effects, calculate spell attacks or grant eligibility. Future magic and psychic adapters can use the same projector with their separate game catalogs. No accepted book definitions change and no complete spell/psychic path is claimed.
