# 22B2C: Shared fixed-grant resolution

**Status:** in-progress. **Base:**20c1c5c1a3e8e9d76f1caed67c29f4c95517e176 (merged22C1/PR93).

Resolve fixed grants through one strict catalog-based engine. Legacy explicit identities and duplicate grant-once behavior remain supported; new declarations may compose exact catalog selectors. Integrate Rifts/Heroes retained Physical grants and Heroes fixed program grants without option/class/race ID handlers. Validate all program grant declarations, including unselected programs, before mutation; preserve exact pins, acquisition dice, program education bonuses, honor warnings and PDF/UI compiled identities. Synthetic declarations prove the data contract, not new accepted book rules. Conditional/level grants and other catalogs remain later work.
