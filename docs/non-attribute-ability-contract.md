# Non-attribute ability acquisition contract

Heroes ability definitions may supply `acquisition_formulas`: a named mapping of ordinary formulas, including `{}`. The adapter validates all declarations against the shared retained-acquisition compiler before new ability dice. Empty groups acquire no dice; nonempty groups retain raw ordinary dice, zero-die constant groups and exact results. Initial-attribute house options do not apply. This shape cannot coexist with legacy attribute floor/additive fields or unsupported executable/implicit effects. Supported metadata: id, name, category, source, guidance, optional tags, parameters, requirements, named mental saving bonuses and typed skill effects.

A selected ability still gets one source-bound UUID receipt and selection history. Removing it retains its receipt; reselecting/importing never rerolls. Attribute modifiers skip this declaration family. It may use the existing common parameter, requirement, numeric saving and acquired-skill effect seams without granting an attribute effect. Acquisition formula groups are recorded/displayed values, not implicit resource or combat mutations.

Catalog/active/inactive views derive a normalized summary, so browser/PDF rendering can reuse the current summary path. Book/section evidence is required; optional page locators use existing common citation formatters. Stored receipt shapes and accepted archives are unchanged.

The current player-facing witness is a synthetic Heroes Minor ability. This does not certify actual sensory powers, magic or psionics, nor their eligibility/selection budgets, learned levels, resource spending, conditional activation or cross-game adapters. Those require separate source-grounded work.
