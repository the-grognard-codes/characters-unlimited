# Issue tracker

Approved implementation slices are tracked as local Markdown under `.scratch/character-creator/issues/`, with one file per ticket and explicit blocking edges. Pull requests are created and merged in the configured GitHub repository for each completed slice, as authorized by the user on 2026-10-02.

Use statuses `ready-for-agent`, `in-progress`, `blocked`, and `done`. A ticket is complete only when its acceptance checks pass and its pull request is merged. Missing corpus content is tracked through the inventory and bounded content tickets; it is not hidden by manual fallback.
