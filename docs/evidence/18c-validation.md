# 18C equipment rule update validation

The production equipment catalog remains 1.0.0. A test-only accepted 99.0.0 definition changes the Wilk's 320 weight from 2 to 3 lb, aimed weapon bonus from +2 to +4, and price from 11,000 to 12,000 credits; Plastic-Man main-body capacity changes from 35 to 40. These fixture values are not published game rules.

Before implementation the public preview omitted equipment corrections and could not apply an equipment-only update. Five public workflow tests now cover read-only previews, a 17 → 19 lb inventory and aimed strike 5 → 7, unchanged possessions/credits, exact portable versions, complete pre-update backup, and a simultaneous skill/equipment update interrupted by a database trigger. Stale/tampered/changed-target previews, failed backup, missing owned items and decreased ammunition capacity preserve the save. An older character without equipment receives no equipment pin.

All 177 global workflow checks pass (one frozen-only skip), along with mypy on 59 files, compilation and all browser-script syntax checks. After dialog label/layout polish, all 16 affected equipment and both-game upgrade checks plus type/JavaScript checks pass. Edge browser preview, apply, backup confirmation and reopen retain the fixture inventory and show corrected 19 lb and 40 main-body capacity. Screenshot: `18c-equipment-preview.png`. Independent Standards: no actionable findings, approve. Independent Spec: no missing, incorrect or out-of-scope behavior, approve. Publication and Windows package validation follow. Parent 18 remains open for other rule families and migrations.
