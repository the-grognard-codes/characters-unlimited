# Aliens Unlimited: 84/85 race-count reconciliation

**Conclusion:** The count is not mechanically reconcilable from the book as printed. The introductory claim is 84; the alphabetical index enumerates 85 catalog profiles across its eleven body groups (six groups of seven, 15 Humans & Humanoids, and four further groups of seven). The optional random-generation tables have 84 rows, but their roster differs: they omit Atorians and list “Mantis,” for which there is no catalog/index entry, where the catalog/index has Manteze. This may explain the numeric 84 only if both are source conventions/typos; the source does not establish that. Preserve this as an unresolved source discrepancy.

| Evidence | Original locator | Finding |
|---|---|---|
| Introductory creation text | Printed p.8 / PDF p.9 | Says players may pick or roll one of “84 specific alien races presented in this book.” |
| Alphabetical race index | Printed p.191 / PDF p.192 (corrected Markdown lines 8430–8480) | Index groups total 85 primary profiles; explicitly includes Atorians p.102 and Manteze p.118. |

Table B p.19/PDF20 says “Mantis (Insect, abrasive atmosphere)”; the catalog/index has Manteze, not Mantis. The printed Table A row is 77–79 Photin, though corrected Markdown OCR renders it `77479` at line 963. |
| Atorian profile | Printed p.102 / PDF p.103; corrected Markdown lines 4599–4620 | Separate indexed/statistical profile titled Atorians (also “a.k.a. Fehrans”); introductory prose says the Atorians appear human. Whether this is excluded from the author's “specific alien races” total is not stated. |
| Manteze profile | Printed p.118 / PDF p.119; corrected Markdown lines 5369 onward | Distinct insect profile indexed as Manteze; no separate Mantis race appears in the catalog index. |

**What remains uncertain:** The 84 count might exclude Atorians because their entry describes them as human-looking, while the random table's “Mantis” may be a typo for Manteze. Neither inference is confirmed by the book. A direct profile-heading count is 85; the random tables contain 84 entries, with the noted roster mismatch.
