# Shared ordinary skill training

The `required_skill_training` format1 capability opts an exact Rifts skill archive into reconciled required, fixed, optional and automatic percentile training. Archives without this declaration retain their previous projection. Physical effects, specialties and domestic repetition retain their separate contracts.

The shared training module resolves the highest applicable ordinary class bonus once and then reconciles automatic training. IQ, source synergies, genuine class abilities and advancement remain separate contributions. Class abilities come from the active required training, rather than another class's catalog defaults. Required and optional copies of the same acquired ordinary skill use the same training and earliest retained learning age. An unavailable optional pool contributes no additional class training; retained choices still receive their existing acquired training.

Required definitions may declare `catalog_skill_id` while retaining their raw IDs and choice values. Whole-pack preflight validates every reference, including unselected options and class profiles, against a known ordinary percentile identity without a specialty. The required base and per-level progression must match the pinned catalog; class training must be a bounded exact integer. Explicit references require source book and section evidence and the reviewed format declaration. Malformed declarations reject before initial character dice.

City Rat's existing `pilot-automobile` and `pilot-bicycle` declarations link to `automobile` and `bicycle`. Projection considers both canonical and declared legacy learning keys, using the earliest recorded acquisition. Saves retain the raw keys and required choices. An explicit rule upgrade adds the current projected learning identities before portable validation, preserving legacy records and historical rule pins. New optional learning does not reset an earlier required acquisition. Undo restores the exact earlier save and rules.
