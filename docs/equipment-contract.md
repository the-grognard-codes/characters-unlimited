# Reviewed equipment inventory contract

The accepted `rifts-equipment` pack is separate from skills and Heroes catalogs. Its immutable item definitions declare category, price in credits, pounds, numerical gun capacity/range/aimed bonus and W.P. ID, source damage text, or armor location capacities and physical-check movement penalty. Source text is never evaluated. Candidate IDs, original printed/PDF locators and book fingerprints retain evidence. `sheet_name` is optional presentation metadata for a narrow reference-sheet field; the full name remains in explanations.

Saved `equipment` contains `credits` and `items`. Each possession keeps a unique ID, catalog item ID, positive quantity (maximum 1000), carried/stored location, equipped flag and per-item current shots (zero through the reviewed gun capacity; null for armor). Rows represent identically conditioned items; separate conditions use separate rows. Credits use supported whole numbers and may be negative. The first explicit inventory action pins the active accepted equipment version atomically with the record; later actions resolve that pin. Newer equipment rules never substitute silently. A general equipment upgrade preview is still pending under 18B.

Purchases debit reviewed unit cost times quantity. Manual credit, quantity, location and shot changes follow the honor system and do not infer extra transactions. Removal does not refund credits. Invalid, stale or cross-game writes leave saved work intact. Portable bundles include and validate exact definitions and inventory structure. No authoring expressions or executable content are accepted.

Projection explains carried weight and lists every possession, including stored items. Only carried/equipped possessions contribute active gun or armor results. Gun single/aimed totals use matching W.P., ordinary aimed training and source weapon bonus; strength/P.P. gun bonuses and unsupported fire modes are excluded. Missing proficiency leaves aimed totals absent; existing low-P.P. gaps and zero recorded shots leave unavailable attack contexts with guidance. Armor capacities are per location, never added to personal S.D.C.; multiple active units retain guidance without invented stacking. Mobility penalties identify physical checks rather than reducing speed universally. The current partial skill catalog contains no supported check to which the armor penalty is numerically applied.

The browser and editable Rifts PDF consume the same projection. PDF export projects all content from one loaded character snapshot, so a concurrent edit cannot combine character states. Weapons and one active armor unit fill original field rectangles; quantities, states, sources, money and full explanations continue in editable note fields. Unsupported/missing values stay blank.

This bounded contract is not the complete ingestion schema or equipment corpus. Starting class equipment/funds, other gear and ammunition purchases, reload workflows, movement-check integration, encumbrance limits, construction and broader contextual effects remain in named follow-up work.
