# Ability paths and natural psionics

`ability-paths-v1` combines a neutral `abilities-v1` catalog with a source-bound percentile table, category memberships, named paths and selection modes. Paths declare saving targets, allowance/category ranges, starting resources and later-level gains. The engine dispatches by declared identities and formulas, never class/race names. Ordinary Rifts natural psionics is the first activated family; existing HU mutant adapters remain compatible and other families still need integration.

Potential is rolled once on D100; choosing to skip leaves the receipt intact, and a skipped character who has never rolled can roll later. The recorded face selects the declared path. Source Step4 yields major1–10, minor11–25, ordinary nonpsychic26–100. Major has8 powers in one category or6 across2–3; minor has2 in one. Category and count discrepancies remain visible guidance. Shared powers have one identity with several category tags; categories without selected powers and choices outside declared categories are reported. No override marker is required.

Starting ISP records effective M.E. once plus2D6 minor or4D6 major. Growth begins at level2: D6 minor, D6+1 major, one receipt per attained level. Selecting the path at a higher level records all attained gains. Skipping retains starting and future cached gains. Undo restores earlier choices while retaining gain receipts; if the path was first selected after the restored checkpoint, it is retained disabled. Later replay uses cached gains. Intermediate snapshots for multi-level advancement include the attained receipts needed for portable replay. No live ISP spending/recovery simulator is introduced.

Whole-profile declarations, inactive receipts, source references and exact content pins preflight. The outer pin covers the complete path pack; the inner pin covers the ability catalog. Application archive pins retain the exact accepted version. Portable validation also verifies the starting attribute snapshot against racial generation, class effects and retained Physical evidence. Current attribute edits do not recalculate that starting contribution. Shared canonical JSON encoding is extracted without changing the existing portable format.

The source proposal script generates56 unique ordinary powers from15 Healing,21 Physical and24 Sensitive checklist entries. It reconciles published heading aliases and skips empty cross-reference headings. A complete56-entry source audit checks the full definitions rather than assuming the first paragraph is sufficient. Curated summaries preserve consequential conditions and repair displaced/OCR prose; explicit metadata repairs costs and durations. Total Recall has a genuine printed conflict (header2 ISP versus prose3 per recalled block); the utility follows3 per detailed block and displays the conflict descriptively. Range/duration/cost metadata remains descriptive. This is a reproducible proposal recipe, not automatic source certification or a general maintainer importer. Super Psionics and psychic O.C.C./R.C.C. entitlements are not activated by this catalog.

The builder displays potential, ISP, psychic saving target, categories, remaining count, searchable options and expandable source descriptions. Saving target12 for enabled major/minor,15 for skipped/nonpsychic, stays separate from existing attribute/class bonuses. The original Rifts sheet receives editable ISP capacity cells and editable notes/continuations with power descriptions and source sections. Existing character saves with no psionic state remain unchanged. Future class/race imports must explicitly compose innate psychic entitlements and their precedence rather than blindly stacking this ordinary natural-potential path.

Remaining release work includes source-backed magic and broader abilities, all supplied applicable class/race options, compatible identity revision, robot/bionic construction, general maintainer ingestion/activation reporting and final release acceptance. This natural path does not certify those capabilities.
