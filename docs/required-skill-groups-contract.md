# 05C1: Declarative required percentile skill groups

This prerequisite for additional O.C.C.s generalizes required percentile grants and choices. It does not activate City Rat or complete parent05/02B11.

Immutable skills2.8.0 preserves Vagabond numerical rules while expressing its existing four groups declaratively. `required` format2 contains fixed `grants` and ordered `groups`. A group declares `id`, player-facing `name`, `kind`, `count`, and source evidence. Text is one string, text-list is a list with one percentile `skill` definition, and select uses its option definitions (one string for count1, a list otherwise). A fixed grant can take its specialty from a single text group. `different_from` names groups whose normalized labels cannot also fill that group. All values are retained, including duplicates and excess; unique valid choices fill slots and bonuses apply once per semantic grant. Unknown option IDs and malformed shapes fail before writing. Empty groups remain incomplete. This interface currently covers percentile grants; automatic Physical/W.P./other grants remain separate supporting work.

Older immutable required definitions are adapted to the same presentation contract in memory. Existing saved native/other languages/pilot/repair keys remain compatible; no pack is silently substituted. Native labels and learned levels, source numerical values, caps, synergies, resource dice, and full historical pins retain their original meaning. Reviewed update previews/applies preserve selections without rolling.

The builder renders labels/options/counts from groups, autosaves changes through the existing protected required-skills route, retains duplicate/excess rows, and keeps pending edits during asynchronous loads/navigation. Multiple select groups can add extra retained slots. Exported percentile skills use the existing native and continuation sheet fields.
